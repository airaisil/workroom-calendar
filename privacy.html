다루는 정보

  • 로그인한 본인의 구글 캘린더 일정(권한: calendar.events). 업무 일정을 넣고, 읽고, 지우는 데에만 씁니다.

보관과 공유

  • 모든 정보는 사용자 본인의 PC에만 저장됩니다. 따로 서버에 올리지 않습니다.
  • 누구에게도 팔거나 넘기지 않고, 광고에 쓰지 않습니다.
  • 구글 사용자 데이터는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

연결 끊기

구글 계정의 '타사 앱 및 서비스' 화면에서 언제든 연결을 끊을 수 있습니다. 끊으면 Workroom은 더 이상 캘린더에 접근하지 못합니다.

Privacy Policy

Data used

  • Events in the signed-in user's own Google Calendar (scope: calendar.events), used only to add, read and remove work events.
  • The access tokens Google issues, used only to keep the connection.

Storage and sharing

  • Everything is stored only on the user's own computer. Nothing is uploaded to any other server.
  • Data is never sold, shared or used for advertising.
  • Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting

You can remove access at any time from "Third-party apps & services" in your Google Account.
